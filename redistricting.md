# Bundeswahlleiter Sources on Redistricting / Wahlkreiseinteilung (2005-2025)

This file lists the Bundeswahlleiter pages for each Bundestagswahl year from 2005 to 2025.

## Links by election year

- 2025: https://www.bundeswahlleiterin.de/bundestagswahlen/2025/wahlkreiseinteilung.html
  - Contains explicit description of changes (including number of newly delimited districts and category tabs).
- 2021: https://www.bundeswahlleiterin.de/bundestagswahlen/2021/wahlkreiseinteilung.html
  - Contains explicit description of changes and number of newly delimited districts.
- 2017: https://www.bundeswahlleiterin.de/bundestagswahlen/2017/wahlkreiseinteilung.html
  - Contains explicit description of changes and number of newly delimited districts.
- 2013: https://www.bundeswahlleiterin.de/bundestagswahlen/2013/wahlkreiseinteilung.html
  - Contains explicit description of changes and number of newly delimited districts.
- 2009: https://www.bundeswahlleiterin.de/bundestagswahlen/2009/wahlkreiseinteilung.html
  - "Karte der Wahlkreise zum Download" page (map/geometries and related resources).
- 2005: https://www.bundeswahlleiterin.de/bundestagswahlen/2005/wahlkreiseinteilung.html
  - "Karte der Wahlkreise zum Download" page (map/geometries and related resources).

## Notes

- For 2013, 2017, 2021, and 2025, the pages include textual redistricting explanations.
- For 2005 and 2009, the available year pages are map/download pages rather than detailed redistricting narratives.
